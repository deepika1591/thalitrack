# ThaliTrack — starter

The starting point for the ThaliTrack course: a meal tracker that reads a photo
of your thali and learns your kitchen.

- `photos/` — 15 real thali photos for testing. Credits and licences: `photos/NOTICE.md`.
- `data/` — nutrition table for 218 Indian dishes and the dish menu. Source: `data/NOTICE.md`.
- `*.py` — empty files you fill in, one or two per video.

This folder came attached to the course. Setup is in video 2. Never put your API key in any file except `.env`,
which `.gitignore` keeps out of GitHub.

Nutrition values are estimates, not medical or dietary advice.
